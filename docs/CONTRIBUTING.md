# Contributing

## 1. Set up development environment

- Make sure PHP and Composer are installed on your machine.
- Run:

```bash
composer setup
```

## 2. Start the development server

- Run:

```bash
composer dev
```

- Open the app in your browser at `http://localhost:8000`.

## 3. Run tests

- Run all checks (including linting) with:

```bash
composer test
```
